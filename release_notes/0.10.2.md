# Snipshot 0.10.2

### Fixes

- Tool property bars (Mosaic / Blur, colors, stroke width) no longer cover the selected image. When the main toolbar sits below the selection, the property bar now appears below the toolbar instead of over the image.

### AI settings

- OpenAI and OpenRouter now use `gpt-6-luna` as the recommended default model.
- The model list hides models that are scheduled for shutdown, legacy GPT-3 to GPT-5 models, and models that cannot read screenshots (image generation, audio, realtime, embeddings).
- A new search field filters the loaded model list.
- The model list now refreshes automatically in AI settings when an API key is configured.
